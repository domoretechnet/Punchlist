Connect your computer

Two minutes, four steps. Works with any MCP-compatible AI tool — Claude Code and Claude Desktop shown below. Requires Node.js 20 or later, phone and computer on the same Wi-Fi.

  1. Enable sharing on your phone In Punchlist, open the Connect tab and switch on Share over local network. A 6-digit pairing code appears — sharing stays on across launches until you turn it off.
  2. Add the MCP server For Claude Code:
    TerminalClaude Code
    claude mcp add punchlist -- npx -y punchlist-mcp
    For Claude Desktop, add to claude_desktop_config.json:
    JSONclaude_desktop_config.json
    {
  "mcpServers": {
    "punchlist": { "command": "npx", "args": ["-y", "punchlist-mcp"] }
  }
}
  3. Pair once Ask your assistant to “pair with my Punchlist device” and give it the 6-digit code. Pairing pins your phone's TLS certificate — every transfer after that is encrypted end-to-end on your network.
  4. Ship the fixes Record a session, then say “pull my latest punchlist session.” Your tool gets the screenshots, the synced transcript, and your standing per-app instructions — and marks the session processed when it's done.
Using something other than Claude? Any MCP client works: point it at the punchlist-mcp command over stdio and the same tools appear — device discovery, pairing, session pulls, and per-app instructions.
