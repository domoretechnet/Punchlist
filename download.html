Punchlist for Claude Desktop

A one-click extension — no config file, no Node setup. Download it, open it in Claude Desktop, and the Punchlist tools appear.

Download the extension

punchlist.mcpb · v0.8.3 · macOS & Windows · Claude Desktop

  1. Download the extension Save punchlist.mcpb using the button above.
  2. Open it in Claude Desktop Double-click the downloaded file, or open Claude Desktop → Settings → Extensions and add it there. Claude installs it and starts the Punchlist server automatically — nothing to configure.
  3. Enable sharing on your phone In Punchlist, open the Connect tab and switch on Share over local network. A 6-digit pairing code appears.
  4. Pair once, then pull sessions Ask Claude to “pair with my Punchlist device” and give it the code. After that, say “pull my latest punchlist session” to get the screenshots and synced transcript. Off Wi-Fi? Run “connect iCloud” once to pull sessions over the internet too.
Using Claude CLI, or another agent? You don't need this file — install over the command line instead. See the Install guide.
